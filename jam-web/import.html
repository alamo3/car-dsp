Import a playlist into CabinEQ

Export the playlist from the service you use, then share the file to CabinEQ.

YouTube Music: in Soundiiz or TuneMyMusic, connect YouTube Music and export a playlist to CSV or JSON.
Spotify: use Exportify, which includes ISRCs and matches almost exactly.

Open CabinEQ

Nothing happens? CabinEQ isn't installed — install it, then open this page again.

You can also share a CSV/JSON file straight to CabinEQ from any file manager, or paste an Artist - Title list in Music → ⚙ → Import playlists.
